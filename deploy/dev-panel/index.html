HoneyForge

Минимальная операторская панель. Сначала устанавливает агент по SSH, затем ставит Low или Middle SSH-ловушку через уже зарегистрированный агент.

1. Подключить VPS

Пароль/ключ используются только для SSH-подключения и не сохраняются браузером. Проверка host key SSH отключена.

2. Поставить ловушку

После bootstrap подожди пока агент зарегистрируется, затем выбери уровень ловушки и порт.

3. Удалить ловушку

Останавливает контейнер и удаляет проект на агенте. Уже отправленные события остаются в центре.

4. Отозвать доступ агента

После отзыва агент больше не сможет подключаться к центру. Сначала удали его ловушки, если они больше не нужны.

5. Скомпрометированные VDS

Center блокирует команды и телеметрию для таких агентов. Повторная установка на тот же hostname/IP запрещена до ручного разбора инцидента.
